# PrintFarm — сайт

Сайт PrintFarm, веб-системи для керування фермою 3D-друку:
**https://bas3dfarm.github.io/printfarm-site/**

На сайті:

- [Можливості](https://bas3dfarm.github.io/printfarm-site/features.html) — дашборд, задачі, замовлення, аналітика, камери, зі знімками екрана
- [Встановлення](https://bas3dfarm.github.io/printfarm-site/install.html) — покроково для Linux
- [Обслуговування](https://bas3dfarm.github.io/printfarm-site/maintenance.html) — журнал, оновлення, бекапи, типові проблеми
- [Що працює](https://bas3dfarm.github.io/printfarm-site/status.html) — що перевірено, а що ні
- [Плани](https://bas3dfarm.github.io/printfarm-site/roadmap.html) — що робимо далі

У цьому репозиторії лише сторінки сайту (статичний HTML). Код самої системи тут не публікується.
