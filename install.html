Встановлення

PrintFarm ставиться як звичайна програма на один комп'ютер у мережі ферми. Далі ним користуються з браузера будь-якого пристрою в тій самій мережі.

2. Як отримати пакет

Пакет printfarm_<версія>_amd64.deb поки видається за запитом: напишіть нам, і ми надішлемо файл та підкажемо з першим запуском.

Контакт: bas126@proton.me

3. Встановити

  1. Покладіть файл пакета в теку /tmp (з домашньої теки теж працює, але система друкує зайве попередження про права — це не помилка).
  2. Відкрийте термінал і виконайте: 
    sudo apt install /tmp/printfarm_<версія>_amd64.deb
    Важливо: повний шлях до файлу (або ./ на початку). Без нього apt шукатиме пакет в інтернеті. Система сама доставить усе потрібне, зокрема ffmpeg для камер.
  3. Без терміналу: подвійний клік по файлу → Центр застосунків → «Встановити» (пароль користувача). Попередження «Потенційно небезпечно» / «Невідомий видавець» Центр показує для будь-якого пакета не з репозиторію Ubuntu.

Що зробила установка:

  • служба printfarm — запущена й стартує сама після перезавантаження комп'ютера, перезапускається після збою;
  • окремий системний користувач printfarm без входу в систему;
  • каталоги даних і налаштувань (див. «Де що лежить»);
  • ярлик «PrintFarm» у меню програм;
  • якщо увімкнений файрвол ufw — відкрито порт інтерфейсу 3000/tcp і 2021/udp (автопошук принтерів Bambu). Вимкнений файрвол пакет не чіпає.

4. Перший вхід

  1. Відкрийте в браузері http://localhost:3000 на цьому комп'ютері або ярлик «PrintFarm» у меню. З інших пристроїв — http://<IP-комп'ютера>:3000.
  2. Перший екран — створення адміністратора. Запишіть логін і пароль. Забули — його можна скинути командою («Забули пароль»).
  3. Налаштування → Користувачі — додайте операторів. Оператор бачить усю щоденну роботу, але не налаштування.
  4. Налаштування → Стелажі — за бажанням: стелажі дають код місця (A23) на картках і в сповіщеннях.

5. Мережа й час

  • Закріпіть IP-адреси принтерів і комп'ютера ферми в роутері (DHCP reservation). Якщо роутер після перезавантаження роздасть нові адреси, ферма шукатиме принтери за старими. Як це виправити, якщо вже сталося, — «Принтери змінили IP».
  • Часова зона. Дні в аналітиці рахуються за часовою зоною комп'ютера. Перевірити: timedatectl (рядок Time zone). Виправити: 
    sudo timedatectl set-timezone Europe/Kyiv
sudo systemctl restart printfarm
  • Інший порт замість 3000 — «Змінити порт».

6. Додати принтери

Налаштування → Принтери → Додати. Завжди потрібні назва, модель і IP-адреса принтера. Решта полів залежить від бренду — форма сама покаже, що потрібно. Після збереження ферма підключається одразу; якщо принтер недосяжний — за ~30 с він стане «офлайн» і повернеться сам, щойно з'явиться в мережі.

Один принтер — одна ферма. Не підключайте той самий принтер одночасно до двох копій PrintFarm чи до іншої програми керування фермою: друга програма бачить ті самі друки і може приписати їх собі.

Bambu Lab

  1. На екрані принтера, у налаштуваннях мережі, увімкніть LAN Only, а потім Developer Mode (назви пунктів трохи відрізняються в різних прошивках). Без Developer Mode ферма бачить стан принтера, але запуск друку принтер відхилить з кодом 0x05024007.
  2. Там же — Access Code (8 символів).
  3. Серійний номер — у налаштуваннях принтера (інформація про пристрій) або на наклейці. У формі ферми є кнопка автопошуку серійника — вона працює, коли комп'ютер і принтер в одній підмережі.
  4. Введіть IP, Access Code і серійник → «Зберегти».

Хибний серійник виглядає як «офлайн» приблизно через 30 с. Хибний Access Code — запис Not authorized у журналі.

Creality K1 / K1 Max, Qidi Q2 (Klipper · Moonraker)

Достатньо IP-адреси. API Key Moonraker — лише якщо на принтері увімкнена авторизація. Тип і колір філаменту з принтера не приходять — вказуються вручну.

Prusa CORE One (PrusaLink)

IP-адреса і API Key: на принтері — Settings → Network → Login credentials.

7. Перевірка

  1. На дашборді принтери мають стати «готовий» (або «друкує», якщо зараз друкують).
  2. Створіть тестове замовлення й задачу з невеликим файлом, відправте на один принтер.
  3. Якщо щось не так — подивіться журнал і типові проблеми.
